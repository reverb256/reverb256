## 📖 The Real Story

Been in love with computers since the IBM 486. DOS Shell. Windows 3.1. Always comfortable in a terminal. Emulated everything. Hooked a GameCube to a PC using the Phantasy Star Online DNS trick to stream GC games. Read every tech blog I could find through school. Broke stuff, fixed it, broke it again — that's how I learned.

Then 15 years in food service while never stopping the obsession. Crypto mining built the GPU farm. VR consumed 2024 (Quest Pro, VRChat, full body tracking). AI got serious late 2025. Blew $1K on Replit learning the hard way. Client web dev for small businesses.

Killed Windows for good September 2025, tried Omarchy, hopped to CachyOS, experimented with Bazzite/Aurora, settled on NixOS in January. As of September 2026 the whole fleet runs Arch-based Omarchy.

All code is AI-generated via agentic pipelines I architect. I define the scope, the AI executes.
